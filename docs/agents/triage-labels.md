# Triage 标签

各 skill 用五个规范 triage 角色表述。本文件把这些角色映射到本仓库议题跟踪里实际使用的标签串。

| mattpocock/skills 中的标签 | 本仓库标签        | 含义                       |
| -------------------------- | ----------------- | -------------------------- |
| `needs-triage`             | `needs-triage`    | 维护者需要评估此议题       |
| `needs-info`               | `needs-info`      | 等待报告者补充信息         |
| `ready-for-agent`          | `ready-for-agent` | 已完整定义，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human` | 需要人来实现               |
| `wontfix`                  | `wontfix`         | 不予处理                   |

当 skill 提到某个角色（如「打上 AFK-ready 的 triage 标签」）时，用表中对应的标签串。

若实际词表变了，改右列即可。
